# @entellix/core

Provider- and persistence-neutral memory-engine decisions shared by Entellix
hosts. The package owns extraction/classification orchestration, policy,
conflict, reconciliation, directives, packet composition, and retrieval logic.

Hosts inject model, persistence, identity, and operational effects through
ports. This package intentionally does not include Entellix SaaS tenancy,
Supabase, RLS, or deployment code.
